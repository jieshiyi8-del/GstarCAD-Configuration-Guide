## 💻 System requirements
Before you install GstarCAD Pro, verify that your computer meets these minimum specifications:

*   Operating System: Windows 11 (64-bit).
*   Processor: Intel Core i5 or AMD equivalent with 2.5 GHz speed or higher.
*   Memory: 8 GB RAM or more for smooth drafting.
*   Graphics: Dedicated GPU with DirectX 11 support.
*   Storage: 5 GB of free drive space.

Ensure you have administrative rights on your Windows account. Without these rights, the installer cannot modify system files or register the software core.

## 🚀 Preparing your Windows environment
Windows 11 often blocks software from unverified sources to protect your system. Follow these steps to clear the way for your installation.

1.  Close all open design programs and web browsers.
2.  Open your Start menu and type "Windows Security."
3.  Go to "Virus & threat protection."
4.  Select "Manage settings" under the protection settings menu.
5.  Temporarily toggle "Real-time protection" to Off. You will turn this back on after the installation completes.
6.  Ensure your Windows system updates are current. An outdated Windows build often causes installation interruptions.

## 🔧 Solving common installation errors
Users frequently encounter three specific issues during setup. Use these fixes if your installation fails.

### Error: Setup failed due to missing libraries
If the setup stops and mentions missing C++ Redistributable files, go to the Microsoft support website. Download and install the latest "Visual C++ Redistributable for Visual Studio." Restart your computer after the install, then run the GstarCAD setup again.

### Error: Access denied
This error means the installer lacks permissions to access your hard drive. Ensure you right-clicked the installer and selected "Run as administrator." If the problem persists, disable your third-party antivirus software temporarily, as these tools often label CAD installers as false threats.

### Error: Compatibility mode
If you receive an error about your operating system, right-click the setup file and select "Properties." Click the "Compatibility" tab. Check the box for "Run this program in compatibility mode for" and select "Windows 10" from the list. Apply the change and try the install process again.

## 📁 Managing your configuration
After a successful install, verify your configuration. Open GstarCAD and check the settings menu.

*   Units: Confirm your drafting units match your project needs (Imperial or Metric).
*   Paths: Navigate to "Options" > "Files" to ensure your support file search paths point to your local installation directory.
*   Hardware Acceleration: Ensure your graphics card support is enabled in the display settings to ensure smooth performance during heavy 3D rendering.

## 📈 Improving performance
Windows 11 includes features that occasionally impede CAD performance. To maximize speed:

1.  Open "Graphics Settings" in the Windows search bar.
2.  Click "Browse" and locate your GstarCAD executable file (usually in the C: drive under Program Files).
3.  Select the app and click "Options."
4.  Switch the graphics preference to "High Performance."
5.  Restart the software.

This signals Windows to dedicate your primary graphics processor to CAD operations, reducing input lag during complex drafting sessions.

## 💡 Final checks
If the software opens but crashes when you open a file, verify your file permissions. Right-click your project folder, select "Properties," and ensure your account has "Full Control" enabled under the Security tab. Consistency in your file management prevents most lock-up issues.
